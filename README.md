# 🔐 Cryptography Algorithms in C++

A C++ implementation of three fundamental cryptographic algorithms:

- 🔑 Caesar Cipher
- 🔒 RSA Encryption
- 🔄 XOR Encryption with Diffie-Hellman Key Exchange

This project demonstrates the implementation of classical and modern cryptographic techniques using C++. It focuses on encryption, decryption, key generation, and secure communication through educational implementations.

> **Note:** These implementations are intended for educational purposes and are designed to help students understand the underlying concepts of cryptography.
